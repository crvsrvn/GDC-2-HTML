HTML 样式规范

html-style 插件模板 · v1.6.3

文档说明

用途
这一页本身就是模板：复制 hs-style、hs-script 与两处标记，只替换正文。
颜色
语义色固定：说明蓝、通过绿、注意琥珀、风险红、要点紫、备注灰；行内编号按前缀自动着色。

1.字体与版心#

正文 Comic Sans MS 16px，行高 1.75。版心固定 988px，在大纲左侧的区域内水平居中；页面底色浅色 #FCFCFB、深色 #151515。标题色条、表头、列表符号和大纲当前位置统一用强调色。

标题层级
元素字号标记
h224px强调色色条
h320px强调色竖条
h417.5px无装饰

2.图表#

图表放进 .hs-zoom；figure 直接包含的图片、SVG、canvas 会被自动包进去。按 F 或双击进入全屏，Esc 退出。

3.标记与原生增强#

3.1状态、记号与 ID#

状态词用标签：已修 未做 已删除 新增。图例符号用记号：= 承接、≈ 换表达、△ 缺口。行内 ID 自动着色，同前缀同色：RT-01、RT-02、SW-R1.7、G15。

注意

能用原生 HTML / CSS 实现的交互，不要再写脚本。颜色必须编码含义，不做纯装饰。

3.2术语与折叠#

版心
正文所在的固定宽度区域。
TOC
右侧大纲，可筛选，随滚动高亮当前章节。

强调二选一：术语、关键词用加粗；需要一眼扫到的结论句用高亮，背景覆盖整段文字；同一处不要既加粗又高亮。脚注用原生弹层，不需要脚本。行内图标： 数据、 流程。

原生 popover 属性配合 popovertarget 按钮即可开合，点击空白处或按 Esc 关闭。

附录：为什么大纲放在右侧

左侧留给正文的起始阅读位置，右侧大纲随滚动高亮，既能定位又不打断阅读动线。
